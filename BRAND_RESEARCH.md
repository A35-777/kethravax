## 1. Executive Summary

This document formalizes the branding investigation for **KETHRAVAX**, an open-source AI system for multi-class structural segmentation and architecture discovery across raw, headerless binary byte streams.

In accordance with project integrity standards, the provisional name **KETHRAVAX** and multiple candidate alternatives were subjected to thorough phonetic, spelling, trademark, and registry searches across GitHub, PyPI, Hugging Face, trademark authorities, and the open web.

**Key Outcome:**  
- **KETHRAVAX** exhibits zero prior usage, zero conflicting trademarks, zero package name collisions, and zero software product conflicts.
- It is approved as the primary project and package name (`kethravax`).
- The neural model family is designated **KethraSeg** (e.g., `KethraSeg-TCN`, `KethraSeg-Hybrid`, `KethraSeg-Micro`).

---

## 2. Investigation Protocol & Search Methodology

The brand clearance process adhered to the following systematic protocol:

1. **Exact & Phonetic Queries:**
   - Exact: `"Kethravax"`, `"kethravax"`, `"kethravax AI"`.
   - Phonetic/Orthographic variations: `"Ketravax"`, `"Kethravac"`, `"Kethrax"`, `"Ketrax"`, `"Ktrax"`.
2. **Registry & Repository Searches:**
   - **GitHub:** Organization, repository, and user query (`site:github.com "kethravax"`).
   - **PyPI (Python Package Index):** Package registry lookup (`site:pypi.org "kethravax"`).
   - **Hugging Face:** Model, dataset, and space index (`site:huggingface.co "kethravax"`).
   - **Open Web & Technical Literature:** Google/Bing indexing for academic publications, corporate products, and open-source tooling.
   - **Trademark & Commercial Databases:** Indian IP (IPIndia), USPTO, EUIPO public search records.
3. **Phonetic & Semantic Conflict Analysis:**
   - Identify whether any variation is associated with existing security, compiler, or reverse-engineering software.
   - Evaluate confusion potential with pharmaceutical or hardware terminology.

### Evaluation of Alternative Candidates

To ensure a defensible decision, four alternative original candidate names were generated and investigated using the identical pipeline:

1. **ByteStratum / StrataByte:**
   - *Status:* Highly crowded. Multiple GitHub repositories and data-storage startups use "Stratabyte" or "ByteStratum". High trademark collision risk.
2. **HexaSect:**
   - *Status:* "Hexasect" has existing usage in geometry tools and gaming scripts. Descriptive but lacks distinctiveness.
3. **SynthoSect:**
   - *Status:* Sounds like synthetic biology or insect control ("insecticide" connotation).
4. **KethraSeg:**
   - *Status:* Completely clean; selected as the specialized **model family name** under the Kethravax umbrella.

## 4. Final Brand Architecture & Visual System

### 4.1 Naming & Positioning Architecture

- **Project Brand:** **KETHRAVAX**
- **Python Package:** `kethravax`
- **CLI Executable:** `kethravax`
- **Model Family:** **KethraSeg**
  - `KethraSeg-TCN`: Temporal Convolutional baseline / production core.
  - `KethraSeg-BiLSTM`: Recurrent sequence boundary baseline.
  - `KethraSeg-Hybrid`: Multiscale CNN + Bidirectional sequence backbone with dual-head boundary refinement.
  - `KethraSeg-Micro`: Low-parameter CPU edge deployment model.
- **Tagline:** *"Precision structural byte segmentation and architecture discovery across raw, headerless binary streams."*
- **Technical Description:** A learned neural and statistical system designed for multi-class structural segmentation of raw binary streams, detecting code architectures, string literal pools, structured jump tables, alignment padding, and compressed payloads without relying on container headers.

### 4.2 Visual Identity Specifications

- **Design Philosophy:** Industrial, technical, obsidian cyber-archaeology. Emphasizes exact byte offsets, hexadecimal matrices, and scientific rigor rather than generic consumer SaaS aesthetics.
- **Color Palette:**
  - `Deep Obsidian Background`: `#090D16` / `#0D111A`
  - `Surface Dark / Card Border`: `#161B26` / `#232B3B`
  - `Cyber Cyan (Code / Accent)`: `#00F0FF`
  - `Emerald (Structured Data / Tables)`: `#10B981`
  - `Amber Gold (String Pools)`: `#F59E0B`
  - `Slate Muted (Alignment / Padding)`: `#64748B`
  - `Violet Purple (High-Entropy / Compressed)`: `#8B5CF6`
  - `Crimson Warning (Ambiguous / Unknown)`: `#EF4444`
  - `Text Primary`: `#F8FAFC`
  - `Text Secondary / Code Offset`: `#94A3B8`
- **Typography:**
  - Display/Headings: `Inter`, `JetBrains Mono`
  - Monospace Data / Hex View: `JetBrains Mono`, `Fira Code`
  - Body: `Inter`, system sans-serif
