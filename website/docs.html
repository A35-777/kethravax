Documentation & Quickstart

How to embed KETHRAVAX into automated reverse-engineering pipelines and CLI workflows.

Installation

Install directly via pip or clone from GitHub:

# Install from PyPI
pip install kethravax

# Or install from source
git clone https://github.com/A35-777/kethravax.git
cd kethravax && pip install -e .

Python SDK Integration

from kethravax import BinarySegmenter

# Load neural segmentation engine
segmenter = BinarySegmenter.load_pretrained()

# Analyze raw byte buffer (e.g. firmware slice)
result = segmenter.analyze_bytes(raw_bytes)

for seg in result.segments:
    arch_tag = f" [{seg.arch.value}]" if seg.category.name == "CODE" else ""
    print(f"[{seg.start:#08x}..{seg.end:#08x}) {seg.category.name:<18}{arch_tag:<14} Conf: {seg.confidence:.1%}")

Command-Line Interface

# Analyze and render visual color-coded terminal report
kethravax analyze firmware.bin

# Export structured JSON report to disk
kethravax analyze firmware.bin --format json -o output.json

# Inspect specific offset with synchronized hex & ASCII preview
kethravax inspect firmware.bin --offset 0x1240 --length 128
