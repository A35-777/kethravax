Architectural Deep Dive

How KETHRAVAX breaks free from heuristic pattern matching and sliding-window blur.

Exact Boundary Snapper

0-Byte Discontinuity Snapper

Sliding-window models smear boundaries across window strides. KETHRAVAX pairs a dilated 1D temporal convolution backbone with a byte-level null discontinuity gradient head to lock boundaries to the exact byte.

  • 0-byte boundary alignment on instruction boundaries
  • Null-discontinuity snapping on padding transitions
  • Eliminates partial opcode truncations
Multi-Architecture

Mixed-ISA Disentanglement

Modern firmware and polyglot exploits combine multiple instruction sets. KETHRAVAX predicts per-byte architecture probabilities, correctly identifying mode switches without symbol tables.

  • ARM32, Thumb-2, AArch64, x86-64, MIPS, RISC-V
  • Dynamic architecture transition penalties
  • Viterbi-constrained sequence decoding
Statistical Calibration

Conformal Risk Control

In security analysis, a confident wrong prediction is dangerous. KETHRAVAX outputs finite-sample calibrated prediction sets, guaranteeing user-specified error bounds on opaque or ambiguous regions.

  • Temperature-scaled softmax calibration
  • Statistical guarantees on ambiguous spans
  • Distinguishes encrypted blobs from compressed data

Developer Quickstart

Integrate KETHRAVAX into your reverse-engineering scripts, automated CI firmware audits, or triage pipelines in minutes.

# Python 3.10+ Integration 
import kethravax

# 1. Load the pre-trained KethraSeg-Hybrid model (100% offline, 48.2K params)
segmenter = kethravax.BinarySegmenter.load_pretrained()

# 2. Segment any raw binary stream without headers
with open("router_dump.bin", "rb") as f:
    raw_bytes = f.read()

result = segmenter.segment_bytes(raw_bytes, calibrate=True)

# 3. Iterate over contiguous, exact 0-byte snapped structural segments
for seg in result.segments:
    print(f"[{seg.start:#08x}..{seg.end:#08x}] {seg.category.name:<18} ISA: {seg.architecture:<10} Conf: {seg.confidence:.1%}")
# CLI Terminal Usage 
# Install KETHRAVAX from repository
pip install .

# Run segmentation on any raw firmware dump
kethravax segment firmware.bin --arch-detect --calibrate --format table

# Export machine-readable JSON for downstream reverse engineering tools
kethravax segment firmware.bin --format json --output segments.json
# C / C++ FFI Binding (Ghidra / IDA Pro Plugin Interface) 
#include <kethravax.h>

kethra_model_t* model = kethra_load_model("kethraseg_hybrid.bin");
kethra_result_t* res = kethra_segment_buffer(model, raw_buffer, buffer_len);

for (size_t i = 0; i < res->segment_count; i++) {
    kethra_segment_t seg = res->segments[i];
    printf("[0x%08zx..0x%08zx] Class: %d Conf: %.2f%%\n", seg.start, seg.end, seg.category, seg.confidence * 100.0);
}
kethra_free_result(res);
# Ephemeral Docker Sandbox Execution 
# Pull and analyze any untrusted binary dump in an isolated sandbox
docker run --rm -v $(pwd):/data ghcr.io/a35-777/kethravax:latest \
    kethravax segment /data/suspect_payload.bin --format json

Frequently Asked Questions

Key technical questions regarding headerless binary segmentation and model guarantees.

How does KETHRAVAX differ from Binwalk or Magika?
Binwalk relies primarily on file magic signatures (e.g. gzip headers, squashfs magic) and entropy heuristics. It cannot segment bare-metal code, detect architecture switches, or isolate jump tables. Magika performs whole-file classification rather than byte-level segmentation. KETHRAVAX provides contiguous, dense per-byte structural segmentation with exact 0-byte boundary snapping even when all headers are stripped.
Does KETHRAVAX require internet access or send telemetry?
No. KETHRAVAX is 100% offline and zero-telemetry. The model weights (48,256 parameters, 192 KB) are bundled with the software and execute entirely on local CPU. No binary data ever leaves your machine.
What architectures are currently identified?
v0.1.0 supports x86-64, ARM32 (ARMv7), Thumb-2 (ARM Cortex-M), AArch64 (ARM64), MIPS32 (Big & Little Endian), and RISC-V (RV32/RV64). The taxonomy also supports polyglot boundaries where multiple architectures appear in the same binary stream.
Can KETHRAVAX detect code inside encrypted or compressed blobs?
No learned model can reverse strong encryption directly from bytes without keys. KETHRAVAX correctly flags encrypted and compressed regions as OPAQUE_PAYLOAD with calibrated high confidence (entropy > 7.9 bits/byte), rather than hallucinating false code classifications.
Can I train custom models on my proprietary firmware corpus?
Yes. The KETHRAVAX repository includes the full dataset generation pipeline, loss functions, and training scripts. You can train specialized models on custom RTOS blobs, DSP architectures, or proprietary microcontrollers.
