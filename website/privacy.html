PRIVACY-FIRST ARCHITECTURE

Privacy & Data Security Policy

KETHRAVAX is built on strict zero-telemetry and local execution guarantees.

1. Zero External Telemetry

Neither the KETHRAVAX Python package, CLI tool, nor web explorer collects, logs, or transmits telemetry, analytics, user identifiers, or binary file content to external servers.

2. In-Browser Client-Side Processing

When you use the Interactive Binary Explorer or in-page playground, your files are read entirely within your browser memory using the HTML5 File API and JavaScript. No bytes are sent over the network.

3. Safe Observational Analysis

KETHRAVAX performs pure static observational feature extraction. It never executes, emulates, or invokes target binary instructions, preventing accidental malware trigger.
