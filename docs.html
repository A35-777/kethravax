Documentation & Integration Guide

Complete reference for installing, configuring, and embedding KETHRAVAX in Python pipelines and command-line workflows.

Installation

Install via pip into your active Python 3.9+ virtual environment:

pip install kethravax

Python SDK Quickstart

Load pre-trained weights and analyze local files or memory buffers:

from kethravax import BinarySegmenter

# Initialize default KethraSeg model
segmenter = BinarySegmenter.from_pretrained("default")

# Segment a binary file
result = segmenter.analyze_file("firmware_dump.bin")

for seg in result.segments:
    print(f"[{seg.start:#010x} - {seg.end:#010x}) {seg.category.value} {seg.confidence*100:.1f}%")

CLI Subcommands

Command Description
kethravax analyze <file> Outputs a color-coded structural table of segments with exact offsets.
kethravax analyze <file> --format json Exports machine-readable JSON segmentation manifest.
kethravax inspect <file> --offset 0x1000 Inspects enclosing segment diagnostics and displays hex dump.
kethravax model-info Displays neural architecture parameters and model card specifications.
kethravax benchmark Prints cached benchmark matrix against baselines.
