## Primary Research Papers

1. **ELISA: Eliciting ISA of Raw Binaries for Fine-Grained Code and Data Separation**
   - *Authors:* Mario Polino, Alessandro Scarselli, Claudio Contini, Luca Rovelli, Michele Carminati, Stefano Zanero.
   - *Publication:* Politecnico di Milano / IEEE / ResearchGate.
   - *Year:* 2021.
   - *Key Topic:* Fine-grained code/data separation in raw binaries using Linear-Chain CRF and logistic regression.

2. **The Good, the Bad, and the Binary: An LSTM-Based Method for Section Boundary Detection in Firmware Analysis**
   - *Authors:* Riccardo Remigio, Alessandro Bertani, Mario Polino, Michele Carminati, Stefano Zanero.
   - *Publication:* In *International Workshop on Security (IWSEC 2023)*, Lecture Notes in Computer Science (LNCS), Springer.
   - *Year:* 2023.
   - *DOI / URL:* https://link.springer.com/chapter/10.1007/978-3-031-41326-1_9
   - *Key Topic:* Bidirectional LSTM for section boundary detection and entropy-based packed architecture classification.

3. **Magika: AI-Powered Fast and Accurate File-Type Identification**
   - *Authors:* Yanick Fratantonio, Luca Invernizzi, Elie Bursztein et al. (Google Security).
   - *Publication:* Google Research / USENIX / ACM.
   - *Year:* 2024.
   - *URL:* https://github.com/google/magika
   - *Key Topic:* Lightweight deep learning file type classification from raw bytes.

4. **FiFTy: Large-scale File Fragment Type Identification using Convolutional Neural Networks**
   - *Authors:* Govind Mittal, Paweł Korus, Nasir Memon.
   - *Publication:* IEEE Transactions on Information Forensics and Security / arXiv.
   - *Year:* 2021.
   - *URL:* https://arxiv.org/abs/2102.10086
   - *Key Topic:* CNN-based file fragment type classification on the FFT-75 dataset.

5. **XDA: Accurate, Robust Disassembly with Transfer Learning**
   - *Authors:* Kexin Pei, Jihun Hamm, Baishakhi Ray, Suman Jana.
   - *Publication:* Network and Distributed System Security Symposium (NDSS).
   - *Year:* 2022.
   - *URL:* https://www.ndss-symposium.org/ndss-paper/xda-accurate-robust-disassembly-with-transfer-learning/
   - *Key Topic:* Masked byte language modeling (BERT-style) for binary disassembly and function boundary recovery.

6. **DeepDi: Learning a Relational Graph Convolutional Network for Fast and Accurate Binary Disassembly**
   - *Authors:* Sheng Yu, Sheng Shen, Lingfei Wu et al.
   - *Publication:* USENIX Security Symposium.
   - *Year:* 2022.
   - *URL:* https://www.usenix.org/conference/usenixsecurity22/presentation/yu
   - *Key Topic:* Superset disassembly and RGCN on instruction flow graphs.

7. **ISAdetect: Automated Machine Learning-Based Identification of CPU Architecture and Endianness**
   - *Authors:* Sami Kairajärvi, Andrei Costin, Timo Hämäläinen.
   - *Publication:* ACM Conference on Data and Application Security and Privacy (CODASPY).
   - *Year:* 2020.
   - *URL:* https://github.com/kairis/isadetect
   - *Key Topic:* Machine learning classification for ISA and endianness identification.

8. **Binary-30K: A Large-Scale Heterogeneous Binary Dataset for Deep Learning**
   - *Authors:* Michael J. Bommarito II et al.
   - *Publication:* Hugging Face Datasets (`mjbommar/binary-30k`).
   - *Year:* 2024.
   - *URL:* https://huggingface.co/datasets/mjbommar/binary-30k
   - *Key Topic:* Multi-platform corpus spanning 30,000 binaries and 15+ architectures.
